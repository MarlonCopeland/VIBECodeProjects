# Assets

These are **placeholder** brand assets (solid UnjadedDigital navy / blue) so a
fresh clone builds without missing-asset errors. Replace them with real
artwork before shipping:

| File                    | Purpose                        | Recommended size |
| ----------------------- | ------------------------------ | ---------------- |
| `icon.png`              | App icon (iOS + base)          | 1024×1024        |
| `adaptive-icon.png`     | Android adaptive foreground    | 1024×1024        |
| `splash.png`            | Splash screen                  | 1284×2778        |
| `favicon.png`           | Web favicon                    | 48×48            |
| `notification-icon.png` | Android notification icon      | 96×96 (monochrome)|

Paths are wired in `app.config.ts`.
